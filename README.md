# Portfólio Alessandro Lacerda

Portfólio estático para apresentação de serviços de desenvolvimento de aplicativos, sites, sistemas, MVPs e automações.

## Executar

Na raiz do projeto:

```powershell
python -m http.server 6060 -d portfolio
```

Abra `http://127.0.0.1:6060`.

- Trocar projetos demonstrativos por projetos reais conforme forem concluídos.
- Adicionar domínio, analytics e formulário de contato definitivo.
